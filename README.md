# 🎓 College Selection Platform

## 📌 Project Overview
The College Selection Platform is a web-based application developed to help 10th students search for eligible colleges based on their academic details. The platform also provides separate dashboards for students and administrators to manage data efficiently.

---

## 🚀 Features

### 👨‍🎓 Student Module
- Student Registration
- Student Login
- Student Profile
- Search Eligible Colleges
- View College Details
- Add/Remove Bookmarks
- Submit College Reviews
- Graphs / Analytics
- Notifications 
- Logout

### 👨‍💼 Admin Module
- Admin Login
- Admin Dashboard
- Add College
- Edit College
- Delete College
- Manage Students
- Manage Reviews
- View Cut-off Graphs

## 📂 Database

Import the SQL database into phpMyAdmin and update the database connection in the `config.php` file.

---

## ▶️ How to Run the Project

1. Install XAMPP.
2. Copy the project folder to:
   ```
   C:\xampp\htdocs\
   ```
3. Start Apache and MySQL.
4. Import the database into phpMyAdmin.
5. Open your browser and run:
   ```
   http://localhost/phpdemo/
   ```

---

## 🎯 Project Objective

The main objective of this project is to simplify the college selection process by allowing students to view eligible colleges based on their academic information while providing an easy-to-use admin panel for managing college records.
